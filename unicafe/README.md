# Zustand Unicafe - exercise 6.1

Based on the official course starter. Feedback counts live in a Zustand store; buttons and statistics select the state they need. Zero feedback displays zero values, following the supplied acceptance tests.

Run npm install and npm run dev here. From ../unicafe-tests run npm install, npx playwright install chromium and npm test.
